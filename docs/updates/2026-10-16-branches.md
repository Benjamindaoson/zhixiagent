| `copilot/add-azure-sql-fabric-connector` `fe484244` | 将 Azure SQL 与 Fabric SQL 加入 `dev` 的模块化连接器注册表；补充敏感字段处理、避免在日志打印密钥、转义 SQL 标识符、限制查询行数并修正 SQL Server 的 `TOP` 与 `ORDER BY` 位置。 | 15 项模拟数据库契约测试通过，包含连接失败时的密钥日志检查；没有目标 Azure 数据库及凭据，尚未证明真实连接。`connectorx` / `pyodbc` 和 ODBC 驱动按需安装。 |

## 已核对但未直接合并

- `copilot/add-refresh-data-option`：`dev` 已有数据刷新对话框、自动刷新设置和 `/api/connectors/refresh-data`，旧分支的实现已被新版流程取代。
- `copilot/fix-remote-mysql-connection`：分支用 `ThreadPoolExecutor` 的上下文管理器实现超时，超时抛错后仍会等待工作线程退出，无法保证调用按时返回；需要改用驱动层或独立执行上下文实现后才能移植。
- `copilot/add-pendidikan-chart-visualization`：分支新增外部 URL 代理，地址校验后仍跟随重定向，可能把请求带到未校验的内网地址；未通过安全审查。
- `mcp`：旧服务直接导入当前 `dev` 已删除的 `DataRecAgent` 和 `ExplorationAgent`，并以 `Workspace(session_id)` 构造工作区，而新版构造函数必须接收用户身份。原服务还从任意 URL 直接下载数据。直接合并会在导入阶段失败，并绕过新版身份与数据访问边界；需单独设计适配层后实现。`chartifact` 的导出能力已单独适配新版图表画布，见[更新 03](2026-10-16-chartifact.md)。
- `copilot/automate-vagalite-script-testing`：布尔类型与 Heatmap 类型修正已由 `dev` 的语义类型解析及图表类型约束覆盖；旧测试套件绑定旧版组装函数，需要按新版契约重新组织。
- `clarity-data-anvil.azurewebsite.net`：只向页面注入外部遥测脚本，没有产品功能，未加入知析 AI。
- `mimetype-js`：本地构建产物 `/DataFormulator.js` 已返回 `application/javascript`，无需额外覆盖 Flask 的 MIME 配置。
- `copilot/fix-20045b03-ae24-4926-9d07-8d79c5ac29cf`：仅修改独立嵌入式演示页，未触及当前应用主流程。
- `codespace-notes`、`test-launch-debugger`、`docs/dev-guides-cleanup`：分别是旧 Codespaces 说明、启动调试器的开发容器设置、开发文档改写；不作为用户功能合并。
- 桌面安装器和 Docker 构建候选分支：需要目标平台安装包或容器构建实测；本轮 Windows Web 运行测试不足以验收这些分支。
- `dependabot/*`：属于独立依赖升级，不当作产品功能合并；需要按锁文件、构建和运行风险单独验证。

其余分支的处置状态见[完整盘点](../upstream-branch-inventory.md)。未合并代表该分支代码未经当前架构验收，不代表永不支持该能力。
