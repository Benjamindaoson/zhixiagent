## 上游 `dev` 新增能力

- **交互式分析应用**：在分析工作区运行受沙箱约束的 HTML/React 应用，涉及前端预览、运行桥接、数据查询和后端沙箱。
- **工作流与定时执行**：新增工作流实例、调度和运行状态管理，涉及 Agent、会话持久化与界面。
- **语义模型与更多连接器**：增加 Power BI、Cube 等数据源与语义模型处理。
- **模型连接与多语言**：扩展模型连接流程和语言资源；对当前已配置的兼容 API 是否有收益，需要单独验证。

上述能力现已进入隔离集成分支。`main...dev` 差异涉及约 598 个文件，其中前端约 191 个、Python 约 159 个；实际合并时处理了 11 个冲突文件，集中在 `App.tsx`、`DataFormulator.tsx`、`DataThread.tsx`、模型/依赖配置和翻译资源。完整验收进度见[逐批更新说明](updates/README.md)。

## 第一项集成：可操作的分析仪表盘

知析 AI 原先已加入交互式分析的轻量仪表盘：在现有工作区中选择已加载的表格、字段、筛选值、图表类型与汇总方式，复用 `/api/tables/sample-table` 读取最多 1,000 行并在前端计算指标。现在也包含 `dev` 的应用生成与沙箱运行代码。两种能力分别验收，样本仪表盘的指标仍只代表已读取的行数。

轻量仪表盘原始实现记录见 `openspec/changes/interactive-analysis-dashboard/`；本次开发分支及其他分支的来源、修复和限制见[更新 01](updates/2026-10-16-dev.md)与[更新 02](updates/2026-10-16-branches.md)。

## 逐项集成的验收边界

1. 为选定能力写明用户流程与依赖；保留首页、五个示例、左侧画布与右侧对话、会话保存、品牌和流式回答显示。
2. 在隔离分支移植该能力及其必要的前后端契约；其他分支先逐项评估与新版架构的兼容性。
3. 使用项目本地依赖环境运行相关测试、TypeScript 检查和生产构建；启动本地服务，浏览器验证首页、原有示例及新能力。
4. 只有通过上述检查，才将该能力并入知析 AI `main` 并更新 README。外部模型、数据库和定时服务若未实际接通，明确标注验证边界。
